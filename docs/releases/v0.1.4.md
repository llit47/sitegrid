# SiteGrid v0.1.4

- **PR25 — workspace and tasks:** redesigned workspace, a separate dashboard with task counts and items needing attention, and compact task cards. Automatic data updates in the visible online application preserve open forms and drafts. An Online/Offline indicator and responsive light/dark themes follow system settings.
- **PR26 — durable offline progress:** IndexedDB v3 queues `start`/`submit` commands from prepared projects. Reconnecting synchronizes the queue while the application is open; retries preserve the original payload and `operationId`. Account, organization and project isolation plus renewed authorization protect access. A 409 conflict preserves the command and blocks further progress without overwriting server data.
- **Release compatibility:** PostgreSQL target/min/max **14**, upgrades **0–14**, with no new or changed migrations. Ed25519 signing, the pinned public key, installer, updater, rollback and GitHub Release workflows remain unchanged.
- **Limitations:** photos and comments require connectivity. No background synchronization (Background Sync); a closed application does not synchronize the queue. Full conflict resolution and discarding/replacing unresolved operations remain pending in M12. After an offline `start` is confirmed, refresh the snapshot online before an offline `submit`.
