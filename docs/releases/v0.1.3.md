# SiteGrid v0.1.3

- PR23 adds chronological, immutable comments to tasks and subtasks, with text, multiple photos, camera/gallery selection, previews, thumbnails and full-size viewing. Shared drafts and lost-response retries preserve the exact payload and comment ID.
- Photos remain private in `/srv/sitegrid/files`. Every original and thumbnail request checks the current session, organization and access to the specific task; there are no public media URLs.
- Schema 14 backups include PostgreSQL and all referenced originals/thumbnails from one consistent snapshot. Restore verifies files, integrity and relationships; incomplete backups fail. Earlier database-only backups remain valid for their original schemas.
- PostgreSQL target/min/max is **14**, with upgrades **0–14**. Rollback requires code compatible with schema 14; returning to schema 13 (including v0.1.2) requires a controlled restore of the pre-upgrade database and matching code. No SQL downgrade.
- Discussions and photos require connectivity. Drafts live only in page memory; no persistent upload queue, offline comments/photos, editing or deletion. HEIC/HEIF requires export to JPEG, PNG or WebP. M08 receipts, M10 snapshots and PWA storage formats remain unchanged.

See [comments, private storage and tested restore procedure](../TASK_COMMENTS_MEDIA.md).
